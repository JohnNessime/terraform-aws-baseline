# `vpc` module

A multi-AZ VPC with three subnet tiers, cost-toggleable NAT, VPC Flow Logs, and
gateway endpoints — the network baseline everything else sits on.

## Design

### Subnet maths, not magic numbers

Subnet CIDRs are derived with `cidrsubnet()` rather than listed by hand. The VPC
is sliced into `/20` blocks (`newbits = 4`), and each tier gets its own band:

| Tier | Blocks | Routes to |
|------|--------|-----------|
| `public` | 0, 1, 2 | Internet Gateway |
| `private` | 4, 5, 6 | NAT gateway (egress only) |
| `database` | 8, 9, 10 | **nothing** — fully isolated |

Change `vpc_cidr` or `az_count` and every subnet re-derives. There is no list to
keep in sync.

### NAT: cost vs. resilience

`single_nat_gateway = true` provisions one NAT for the whole VPC. A per-AZ NAT
costs roughly \$32/month each, so a two-AZ prod VPC pays ~\$64/month for NAT
alone. The tradeoff: one shared NAT means a single-AZ outage cuts private egress
for *every* AZ. Dev accepts that blast radius; prod does not.

### Isolated database tier

Database subnets have route tables with **no default route** — no IGW, no NAT.
Nothing in the database tier can reach or be reached from the internet. AWS
service access (e.g. Secrets Manager over its interface endpoint, or S3/DynamoDB
via the gateway endpoints) is the only egress path you'd add.

### Gateway endpoints

S3 and DynamoDB gateway endpoints are free and keep that traffic on the AWS
backbone instead of billing it through the NAT gateway's per-GB processing.

### Flow logs

When enabled, all traffic is logged to a CloudWatch log group encrypted with a
dedicated, rotation-enabled KMS key. A scoped IAM role lets the flow-log service
write only to that group. Satisfies Checkov `CKV2_AWS_11`.

### Locked default security group

`aws_default_security_group` is managed with zero rules, so the VPC's default SG
denies all traffic rather than shipping AWS's permissive default
(`CKV2_AWS_12`).

## Usage

```hcl
module "vpc" {
  source = "../../modules/vpc"

  name_prefix             = module.tags.name_prefix
  vpc_cidr                = "10.0.0.0/16"
  az_count                = 2
  enable_nat_gateway      = true
  single_nat_gateway      = true # dev: accept the AZ-failure blast radius
  enable_flow_logs        = true
  flow_log_retention_days = 7
}
```
