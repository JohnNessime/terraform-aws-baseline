# `environments/dev`

Thin composition root for the **dev** environment. It declares no resources of
its own — it wires the `tags`, `vpc`, and `iam` modules together with
dev-appropriate settings.

## What makes dev *dev*

| Setting | dev | prod | Why |
|---------|-----|------|-----|
| NAT gateways | single, shared | one per AZ | Saves ~$32/mo; accepts AZ-failure blast radius |
| Flow log retention | 7 days | 365 days | Dev traffic isn't kept for a year |
| AZs | 2 | 3 | Enough to be multi-AZ without over-provisioning |
| OIDC provider | **created here** | referenced | It's account-global — created once |
| CI branch | `develop` | `main` | Each environment trusts its own branch |

## Use

```bash
cd environments/dev
cp backend.hcl.example backend.hcl            # fill from bootstrap outputs
cp terraform.tfvars.example terraform.tfvars  # fill in ARNs / repo
terraform init -backend-config=backend.hcl
terraform plan
```

Both `backend.hcl` and `terraform.tfvars` are gitignored.
